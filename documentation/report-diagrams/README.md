# Report Diagrams

These Mermaid diagrams are intended for the report chapter "Analise e desenho da solucao".

Files:

- `domain-model.mmd`: conceptual domain model
- `use-cases.mmd`: main use cases by actor
- `solution-architecture.mmd`: high-level solution architecture
- `deployment-diagram.mmd`: deployment view with application, worker/scanner and messaging servers
- `discovery-sequence.mmd`: discovery execution flow
- `enrichment-sequence.mmd`: enrichment execution flow

You can render them with:

- Mermaid Live Editor
- draw.io / diagrams.net Mermaid import
- VS Code Mermaid preview extensions

If the report requires UML styling, these files can be used as the source for redraw in draw.io or Visio.
